# Image Generation using VanillaGAN and ProGAN

## Objective

This projects is the final assignment of `Deep Learning for Computer Vision` course, aims at familiarizing you with training, validation and testing a Generative Adversarial Network (GAN).

The objective is building a GAN architecture consisting of at least 1 Discriminator and 1 Generator of which the architectures are of your choice. Then, train and generate images for ONE class of the `CIFAR-10` dataset using VanillaGAN and ProGAN.

`CIFAR-10` dataset consists of 60,000 32x32 color images in 10 classes, with 6,000 images per class. There are 50,000 training images and 10,000 test images. 

## What is Generative Adversarial Network (GAN)? 

Generative Adversarial Network, or GAN, is a deep learning architecture for training generative models to use in image generation. The model architecture involves 2 sub-models:

- **Generator**: The model takes random noise as input and converts it into complex data samples like images. 
- **Discriminator**: The model used to classify input examples as `real` (from the training dataset) or `fake` (generated by the Generator).

These sub-models will compete against each other to improve themselves, resulting in a good Generator to generate images.

- `VanillaGAN`: The simplest type of GAN. The Generator and Discriminator are simple basic MLP.

- `ProGAN`: The Generator and Discriminator sub-models grow progressively over the training process. Training will start with small, low-resolution images (e.g. 4x4) and gradually move to a higher resolution. This approach stabilizes the training process by allowing the network to focus on simpler tasks (low resolution) before handling more complex ones.
